# Итоги: что сделано

Простыми словами: **полный прогон на всех 3888 записях ещё не запущен** (это осознанно
оставлено Голикову — код для этого готов и проверен), но **вся "обвязка" вокруг
обучения готова и проверена, включая саму загрузку данных**: как скачать BUT PPG, как
разбить по испытуемым, чем мерить качество модели, как превратить данные в формат под
конкретную модель, как понимать ответ OpenTSLM, какая архитектура у CNN. Часть этого
кода прогнана не только на придуманных данных, но и на настоящих, скачанных с PhysioNet
— с реальным багом, который на выдумке было physически не поймать (детали ниже).

## Таблица: какой файл что делает

| Файл | Что делает | Откуда берёт данные (вход) | Что выдаёт (выход) |
|---|---|---|---|
| `scripts/prepare_but_ppg.py` | Скачивает BUT PPG с PhysioNet, строит реестр | ничего (сам качает с интернета) | `registry.csv` + `.npy`-окна PPG/ACC |
| `src/butppg/data/registry.py` | Сохраняет/читает реестр, проверяет схему | таблица записей | проверенный `registry.csv` |
| `scripts/make_splits.py` | Делит испытуемых на train/val/test 60/20/20 | `registry.csv` | `splits/*.json` |
| `src/butppg/data/splits.py` | Логика разбиения + защита от утечки данных между частями | таблица записей с метками | список испытуемых по частям + файл разбиения |
| `src/butppg/metrics/quality.py` | Считает качество классификации (good/bad) | истинные метки + предсказания (0/1), опционально вероятность | Macro-F1, Accuracy, ROC-AUC, точность/полнота по классам, матрица ошибок |
| `src/butppg/metrics/hr.py` | Считает ошибку предсказания HR | истинный HR + предсказанный HR (числа, уд/мин) | MAE, RMSE |
| `src/butppg/metrics/predictions.py` | Сохраняет/читает файл предсказаний в едином формате | таблица предсказаний одной модели | проверенный CSV (или ошибка, если формат сломан) |
| `src/butppg/evaluation/evaluate.py` | Главная логика оценки — берёт файл(ы) предсказаний и считает по ним метрики | CSV-файл(ы) предсказаний | метрики + отдельно метрики сценария "сначала отсеять плохие сигналы → потом HR только на хороших" |
| `scripts/evaluate.py` | Командная строка поверх файла выше | аргументы: файл / `--all` / `--pipeline` | JSON с метриками в `artifacts/metrics/` + текст в терминал |
| `src/butppg/models/trivial.py` | Три "простые" модели — нижняя граница, с которой сравниваются все остальные | таблица окон (реестр) с метками | предсказания в том же формате, что и у настоящих моделей |
| `src/butppg/data/marts.py` | Общие функции: прочитать реестр+разбиение, изменить частоту сигнала, нормализовать | `registry.csv` + `split.json` + файлы окон `.npy` | numpy-массивы, готовые под конкретную модель |
| `scripts/build_mart_sigma_ppg.py` | Готовит данные в формате, который понимает SIGMA-PPG | реестр + разбиение (через `marts.py`) | `.npy`-файлы по каждому испытуемому (сигнал на 50 Гц + метки) |
| `scripts/build_mart_opentslm.py` | Готовит данные в формате, который понимает OpenTSLM | тот же реестр + разбиение | `.jsonl`-файлы: текстовый промпт (сигнал + вопрос + правильный ответ) |
| `src/butppg/models/opentslm_parsing.py` | Превращает текстовый ответ OpenTSLM в число/класс | сырой текст ответа модели | класс (0/1) или HR (число) + пометка "ok"/"invalid" |
| `src/butppg/models/cnn1d.py` | Архитектура нейросети (1D-CNN / ResNet1D) для качества и HR | тензор PPG-сигнала (и опционально ACC) | одно число на выходе (в задаче качества — это логит, в задаче HR — сам уд/мин) |
| `tests/` (76 тестов) | Проверяют всё вышеперечисленное | синтетика + 12 настоящих записей с PhysioNet | 76/76 проходят |

## Как данные текут по цепочке

```
PhysioNet (BUT PPG v2.0.0, открытый доступ)
        │  scripts/prepare_but_ppg.py                                готово, не запущено на всём датасете
        ▼
registry.csv + splits/*.json    ← scripts/make_splits.py             готово, не запущено на всём датасете
        │
        ├──▶ build_mart_sigma_ppg.py  ──▶ витрина SIGMA-PPG (.npy)    готово
        ├──▶ build_mart_opentslm.py   ──▶ витрина OpenTSLM (.jsonl)   готово
        └──▶ (напрямую, без витрины) ──▶ модель CNN (cnn1d.py)        архитектура готова
                    │
                    ▼  (после обучения — которого пока нет ни у одной модели)
        predictions/*.csv  (единый формат: record_id, y_true, y_pred, ...)
                    │
                    ▼
        opentslm_parsing.py  (только для OpenTSLM — текст → число/класс)
                    │
                    ▼
        scripts/evaluate.py  ──▶  метрики (Macro-F1 / ROC-AUC / MAE / RMSE / ...)
```

Всё, что выше линии "predictions/*.csv", кроме самой загрузки данных, в реальности пока
не запускалось на полном датасете — обучающегося кода моделей ещё нет ни у одной модели.
Загрузка данных и всё, что ниже линии (оценка), проверены и на синтетике, и на реальных
данных с PhysioNet.

## Что уже можно потрогать руками

```bash
# скачать датасет (полностью, ≈45–90 минут; --limit N для быстрой проверки)
python scripts/prepare_but_ppg.py --out-dir data/processed

# разбить по испытуемым 60/20/20
python scripts/make_splits.py --registry data/processed/registry.csv --out splits/but_ppg_60_20_20.json --seed 42

# собрать витрину под модель
python scripts/build_mart_sigma_ppg.py --task quality --registry data/processed/registry.csv --split splits/but_ppg_60_20_20.json --out artifacts/data_marts/sigma_ppg

# оценить любой готовый файл предсказаний
python scripts/evaluate.py artifacts/predictions/какой-то_файл.csv

# сквозной сценарий "сначала quality, потом HR только на принятых"
python scripts/evaluate.py --pipeline predictions_quality.csv predictions_hr.csv
```
