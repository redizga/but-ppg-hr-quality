## Что сделать первым делом

```bash
# 1. Поставить зависимости заново — добавился wfdb (для скачивания с PhysioNet)
pip install -e .

# 2. Скачать датасет целиком (~45–90 минут, можно в фоне; безопасно перезапускать,
#    если прервётся — уже скачанные .npy не перекачиваются)
python scripts/prepare_but_ppg.py --out-dir data/processed

# 3. Разбить по испытуемым 60/20/20
python scripts/make_splits.py \
    --registry data/processed/registry.csv \
    --out splits/but_ppg_60_20_20.json --seed 42

# 4. Проверить, что тривиальные baseline и оценщик реально работают на полном датасете
python -c "
from butppg.data.registry import load_registry
from butppg.models.trivial import MajorityClassQuality
from butppg.metrics.predictions import save_predictions
reg = load_registry('data/processed/registry.csv')
print(reg.shape, reg['subject_id'].nunique(), 'subjects')
"
```

После этого у тебя будет первый **настоящий** результат в основной таблице (раздел 10
задания) — тривиальные baseline на всём датасете, не на 8-32 тестовых записях.

## На что обратить внимание при первом реальном прогоне

- **`has_acc`** — сколько записей реально получили ACC, я проверял только на паре
  записей вручную. В доке датасета упоминается порог "112001+", но в коде я его не
  зашивал (пробуем скачать, не вышло — не страшно) — посмотри реальную цифру в выводе
  скрипта.
- **Баланс сплита** — `make_splits.py` печатает среднюю метку качества и средний HR по
  каждой части. Если сильно перекошено — можно перезапустить с другим `--seed` или
  добавить `hr_ref` в `--balance-on` (сейчас по умолчанию только `quality_label` +
  `measurement_site`).
- **`prob_good` возвращает N=3888, а не ровно, как ты ожидал** — проверь `quality-hr-ann.csv`
  на предмет пропусков/дублей, если счётчики не сойдутся.
