# Календарный план и декомпозиция

Воспроизводимое исследование на **BUT PPG v2.0.0**: классификация качества PPG
(задача A) и предсказание HR (задача B). Период: **27.07 — 20.08**, 4 недельных
спринта, 2 исполнителя.

> Интерактивная версия плана (Gantt + приоритеты): [plan.html](plan.html).

## Распределение

| Исполнитель | Зона ответственности |
|---|---|
| **Голиков** | данные BUT PPG, классические ML-модели, SIGMA-PPG |
| **Будилов** | метрики/оценка, deep-модели, OpenTSLM, GalaxyPPG |
| **Совместно** | инфраструктура, low-data, финальные таблицы |

## Спринты

### Спринт 1 · 27.07 — 02.08 · Фундамент
- **Совместно (E0):** скелет репо, окружение, конфиги, seed, каркас README.
- **Голиков (E1):** загрузка + предобработка BUT PPG, окна 300 точек, решение по ACC; разбиение 30/10/10 + авто-проверка + баланс.
- **Будилов (E2):** метрики, формат предсказаний, тривиальные baseline.
- *Контрольная точка:* сплиты готовы, harness считает метрики, тривиальные baseline на тесте.

### Спринт 2 · 03.08 — 09.08 · Baseline
- **Голиков (E3):** признаки + LogReg/XGBoost, 4 варианта входов; **старт E6** — изучение SIGMA-PPG.
- **Будилов (E4):** 1D-CNN/ResNet1D для качества и HR; **старт E5** — адаптация OpenTSLM (лоадер, промпты, разбор ответа).
- *Контрольная точка:* все baseline дают метрики на тесте; репо SIGMA и OpenTSLM изучены.

### Спринт 3 · 10.08 — 16.08 · Продвинутые модели
- **Голиков (E6):** дообучение SIGMA-PPG (only-PPG); сквозной сценарий quality→HR.
- **Будилов (E5, E7):** два запуска OpenTSLM (без/с ECG); GalaxyPPG — инверсия, окна, MAE по активностям.
- *Контрольная точка:* SIGMA и OpenTSLM обучены, GalaxyPPG посчитан.

### Спринт 4 · 17.08 — 20.08 · Финал
- **Совместно (E8, E9):** low-data 25/50/100% (каждый по своим моделям, ≥3 сида); итоговые таблицы; полный прогон end-to-end; README; проверка воспроизводимости.
- *Контрольная точка:* репозиторий воспроизводим end-to-end, все таблицы собраны.

## Что режем первым, если не успеваем

1. Вариант с 3-осевым ACC для OpenTSLM (в задании — «если останется время»).
2. Расширенные входы PPG+ACC+covariates (основная таблица «только PPG» важнее).
3. Дополнительные сиды в low-data сверх минимума (3 для 25% и 50%).
4. Low-data для тяжёлых моделей (оставить features + CNN + SIGMA, OpenTSLM только на 100%).
5. Второй запуск OpenTSLM с ECG — крайняя мера, режем только при полном дефиците GPU.
